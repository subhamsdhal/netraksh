# NETRAKSH — backend-only runtime dependencies.
#
# requirements.txt (the original file) installs the FULL stack — edge
# (ultralytics/opencv/easyocr/retina-face/scikit-learn) AND backend — because
# local dev runs both from one Python environment. The backend container
# (Dockerfile) only ever runs `backend.main:app`; it never imports edge code
# at all. Installing the edge stack into it would pull in torch/tensorflow-
# scale dependencies for nothing, multiplying build time and image size for
# a deploy that has real free-tier build-time and memory limits. This is
# the actual import list backend/ and shared/ need — verified by grepping
# every top-level import in both, not guessed.

# passlib's backend-detection code reads, causing a trapped-but-noisy
# warning locally and a hard crash in production (Render resolved an
# unpinned `bcrypt` to a newer version than this dev machine happened to
# have installed). See backend/security/auth.py's _truncate_for_bcrypt for
# the other half of this fix (the 72-byte limit).
